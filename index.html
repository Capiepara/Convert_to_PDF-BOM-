Stage

    PDFs are redrawn from the Excel content using each sheet's print area, paper size and fit-to-page scale. Sharp vector keeps text, borders and fills as real vector graphics (crisp at any zoom, text can be selected). Fonts are replaced by Arial/Times/Courier look-alikes squeezed to the original Calibri widths; text with Chinese or other non-Western characters, and pictures, are embedded as images. Exact fonts (image) reproduces your own fonts but as a picture, so it gets blurry when zoomed. Hidden sheets are skipped. Auto-fit row height (on by default) makes rows taller in the PDF when their text does not fit, including merged cells, so text is not cut off; the Excel file is not changed.

    DXF files (CAD drawings: printed at real size, 1:1)

      Illustrator saves a full PDF copy of the artwork inside every .ai file saved with "Create PDF Compatible File". The tool keeps that PDF exactly as Illustrator wrote it (vector, no quality loss) and only gives it the new name. The PDF is about the same size as the .ai file. If a file was saved without that option, re-save it in Illustrator with the option ticked. PDF files are kept as they are and only renamed. DXF files (ASCII, any AutoCAD version) are redrawn as sharp vector lines at real size (1:1), so a ruler on the drawing measures correctly when printed at "Actual size".
